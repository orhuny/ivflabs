# Doctor Images

This folder should contain the photos for the doctors displayed on the website.

## Required Images

Please place the following images in this folder:

1. **`dr-sevket-alpturk.jpg`** - Photo of Dr. Şevket Alptürk
   - Operating Gynecologist, Founder & Clinical Director
   - Born 1959 in Nicosia, North Cyprus

2. **`fatma-tertemiz.jpg`** - Photo of Fatma Tertemiz (MSc)
   - Specialist Embryologist, Founder & Director
   - Born 1980 in Famagusta, North Cyprus

## Image Requirements

- **Format**: JPG or PNG
- **Recommended Size**: 800x1000px (portrait orientation)
- **File Size**: Optimized for web (under 500KB recommended)
- **Quality**: High resolution, professional photos

## How to Add Images

1. Download the photos from www.cyprusivflabs.com or obtain them from the clinic
2. Rename them exactly as specified above
3. Place them in this `public/doctors/` folder
4. The images will automatically be displayed on the website

## Current Status

The website is configured to display these images. Once you add the image files, they will appear in the "Our Expert Team" section.
