Bu klasör, web sitesinde kullanılan tüm görselleri içerir. Tüm görseller yerel olarak `public/images/` klasöründe saklanmaktadır ve production'a deploy edildiğinde git ile birlikte gelecektir.

## Klasör Yapısı

- `blog/` - Blog yazıları için görseller
- `treatments/` - Tedavi yöntemleri için görseller
- Ana klasör - Genel görseller (bebek fotoğrafları, Kıbrıs görselleri, vb.)
